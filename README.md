# signbridge-site

Public page for the SignBridge iOS app, served with GitHub Pages from `main`.

- `index.html`, `privacy.html`: French
- `en/index.html`, `en/privacy.html`: English
- `style.css`: shared styles, colours from the SignBridge design system (cream `#FAF3E3`, near black `#17130F`, one orange `#F28224`, SF)
- `img/`: logo, favicon, the horizon background (from the App Store header) and the iPhone screenshots (from the 1.1 App Store set; Adonis's image consent covers the website)

The page never gives a number of signs or a list of them: the vocabulary grows with each version.
